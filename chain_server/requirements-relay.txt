# NeMo Relay tracing for the Deep Agents runtime. Optional, and deliberately
# not in requirements.txt.
#
# It needs langgraph>=1.2.9 and this service pins 1.2.7, so installing it means
# moving the agent runtime -- which is a decision to take on its own evidence,
# not one to make on the way to adding tracing. The code path is safe either
# way: with RELAY_ENABLED unset nothing is imported, and with it set but the
# package absent the runtime logs once and runs untouched.
#
#   pip install -r requirements.txt -r requirements-relay.txt
#
# and raise the langgraph pin in requirements.txt to >=1.2.9,<2 when that
# bump has been tested on its own.
